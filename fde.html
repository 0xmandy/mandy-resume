2026.07 · 个人项目Personal Project AI 工程 · 检索增强生成（RAG）AI Engineering · Retrieval-Augmented Generation

招股书 RAG 问答 demo — 带出处、可评测、有数字防火墙 Prospectus RAG Q&A Demo — cited, measurable, with a number firewall

背景BACKGROUND
一份招股书四百多页，人工找一句话要翻很久。我想把它变成「问一句、带出处答一句」的可检索知识库；同时财务数字必须可信，不能让大模型信口。 A prospectus runs 400+ pages; finding one sentence by hand takes ages. I wanted to turn it into a retrievable knowledge base that answers a question with its source attached — while keeping financial figures trustworthy, never left to the model to guess.
挑战CHALLENGE
大模型容易编造或照抄数字；答案要能溯源到具体页码；改一处参数不能凭感觉说「变好了」，得能量化。 LLMs tend to fabricate or blindly copy numbers; answers must trace back to a specific page; and tweaking one parameter can't be called "better" on a hunch — it has to be measured.
方案SOLUTION
搭了一条完整 RAG 管线：按章节切块（带页码元数据）→ 向量化 → Chroma 向量库 → 检索 top-k → 让 LLM 只照检索到的片段作答、每个结论标（第X节·pY）出处。两道闸是关键：数字防火墙——具体财务数值一律不由 LLM 复述、导向确定性取数工具，杜绝幻觉；评测 harness——人手写 gold 考卷（可答 / 该拦数字 / 该拒答三类），自动量检索命中率、带出处率、数字越界数，用数据迭代而非凭感觉。 Built a full RAG pipeline: section-aware chunking (with page metadata) → embeddings → a Chroma vector store → top-k retrieval → an LLM answering only from retrieved fragments, each conclusion tagged with its source (§X·pY). Two gates matter most: a number firewall — specific financial figures are never restated by the LLM but routed to a deterministic data tool, killing hallucination; and an eval harness — a hand-written gold set (answerable / number-firewall / out-of-doc) that auto-measures retrieval hit-rate, citation rate, and number-leakage, so iteration is driven by data, not feel.
价值IMPACT
初始 gold 集（3 题，覆盖三类）全部达标：检索命中率 100%、数字越界 0。同一套管线换标的只改参数即复用（已在长鑫、宇树两家跑通地基）。这套「检索 + 出处 + 防火墙 + 评测」正是把大模型落进严肃业务、让结果可信可溯源的做法。 On the initial gold set (3 questions across all three types): 100% retrieval hit-rate, zero number-leakage, all passing. The same pipeline transfers to a new target by changing parameters (foundations run on two prospectuses so far). This "retrieval + citation + firewall + eval" pattern is exactly how you land an LLM into serious business with trustworthy, traceable output.

2026.06 – 至今Present · 个人项目Personal Project 研究 → 交付 · 具身智能Research → Delivery · Embodied AI

机器人产业知识图谱 — 已发布 8 篇 HTML 研究合集 Robotics Industry Knowledge Atlas — 8 published HTML research pieces

背景BACKGROUND
具身智能是资本最热的赛道之一，但公开讨论充斥二手转述和情绪叙事。我要用基本面研究的方法论，做一套从术语、发展史到文献奠基人、月度跟踪的产业链知识库。 Embodied AI is one of the hottest sectors in venture capital, yet public discussion is full of second-hand retellings and hype. I set out to apply fundamental-research methodology to build an industry knowledge base spanning terminology, category histories, foundational literature, and monthly tracking.
挑战CHALLENGE
跨机械、感知、AI 多学科的术语门槛；历史叙事容易被后见之明扭曲，必须回到当年的一手材料；每个商业化判断都要能被反例证伪，而不是讲故事。 Terminology cuts across mechanics, perception, and AI; historical narratives get distorted by hindsight, so claims must trace back to primary materials from the time; and every commercialization judgment has to survive falsification against counterexamples — not just tell a good story.
方案SOLUTION
三条纪律贯穿全站：第一手信源为据、结构化框架、不确定处诚实标注。用「术语拟人图鉴」降低阅读门槛，用清洁机器人等已跑完商业化周期的品类做参照系，提炼出品类商业化的两条件判断框架，并用割草机器人等品类回测证伪。AI 负责检索与核验加速，结论由人工把关。 Three disciplines run through the whole site: first-hand sources only, structured frameworks, and honest flagging of uncertainty. A "personified terminology field guide" lowers the reading barrier; categories that have completed their commercialization cycle (e.g. cleaning robots) serve as reference systems, distilled into a two-condition framework for category commercialization — back-tested for falsification against categories like robotic lawn mowers. AI accelerates retrieval and verification; conclusions stay human-vetted.
价值IMPACT
已发布 8 篇 HTML 研究作品，形成可复用的品类商业化分析框架；同一套「信源纪律 + AI 加速」的工作流，可以迁移到任何硬科技赛道的尽调与行业研究。 Eight HTML research pieces published, plus a reusable framework for analyzing category commercialization; the same "source discipline + AI acceleration" workflow transfers to due diligence and industry research in any hard-tech sector.
